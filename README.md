# Landing Caminos del Tigre

Landing institucional, responsive y accesible construida con HTML, CSS y JavaScript sin dependencias de ejecución.

## Dirección visual

Composición editorial de gran escala, jerarquía tipográfica marcada y espacios amplios. Combina azul institucional, amarillo de énfasis y una línea tricolor, con superficies cálidas para contenido humano. Los espacios de fotografía se entregan como marcadores descriptivos hasta recibir imágenes autorizadas.

## Mapa de secciones

Barra institucional, encabezado, hero, presentación, funcionamiento, público, cobertura, resultados, historias, preguntas frecuentes, llamado final, contacto y pie institucional.

## Componentes

- Encabezado responsive y navegación por anclas.
- Marcadores de imagen con proporción y texto alternativo sugerido.
- Secuencia de cinco pasos.
- Perfiles habilitados y cobertura territorial.
- Acordeón accesible.
- Formulario demostrativo con validación nativa.
- Pie institucional y mapa del sitio.

## Contenido pendiente

- URL pública de registro y URL de consulta.
- Cobertura y perfiles definitivos del lanzamiento.
- Campos y requisitos definitivos del formulario.
- Cifras verificadas, fecha de corte y fuente.
- Fotografías, historias y autorizaciones.
- Enlaces legales definitivos y fecha oficial de publicación.

## Uso local

Abra `index.html` directamente o sirva la carpeta con un servidor estático:

```powershell
python -m http.server 4173 --directory landing-caminos-tigre
```

Luego visite `http://localhost:4173/`.
